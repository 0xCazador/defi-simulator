# Defi Simulator

Repository for [defisim.xyz](https://defisim.xyz), an unofficial, community-built Aave debt simulator and liquidation calculator.

Contact us on Twitter @defisim

Localization and translation provided by [https://translation.io](https://translation.io)

## Environment

| Variable | Required | Purpose |
| --- | --- | --- |
| `NEXT_PUBLIC_ALCHEMY_API_KEY` | yes | RPC key used by the browser to read positions. Origin-locked in Alchemy. |
| `ALCHEMY_SERVER_API_KEY` | no | RPC key **without** an origin allowlist, used only by server-side code. |
| `NEXT_PUBLIC_SITE_URL` | no | Overrides the canonical origin (defaults to `https://defisim.xyz`). |
| `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` | no | Emits the Search Console `google-site-verification` meta tag. |

`ALCHEMY_SERVER_API_KEY` is what makes the live reserve tables on `/` and
`/interest` work. The public key is restricted to allowlisted browser origins,
so Alchemy answers requests with no `Referer` — which is every request made at
build or revalidate time — with `403 Unspecified origin not on whitelist`.
Without a server key the pages still build and render; they just omit the
parameter tables. Create a second Alchemy key with no origin restriction and
set it in the Netlify environment.

## SEO

Indexable surface: `/` and `/interest`, prerendered once per locale (124 URLs).
Share routes (`/s/{id}`, `/share-fallback`) are deliberately `noindex`.

- `public/robots.txt` — static, advertises the sitemap.
- `/sitemap.xml` — served by `pages/api/sitemap.ts` through a rewrite in
  `next.config.js`. An API route rather than a page so pages-router i18n does
  not fan it out into 62 locale-prefixed copies.
- `utils/seo.ts` — canonical and hreflang derivation, shared by the sitemap and
  `components/SeoHead.tsx` so the two can't disagree.
- `utils/seoContent.ts` — the crawlable copy, resolved per locale in
  `getStaticProps`. Locale activation for the global i18n singleton happens in a
  client effect, so anything rendered with `<Trans>` is English in the
  prerendered HTML; this copy goes through `loadServerI18n` instead so the
  localized URLs are genuinely localized rather than 62 identical duplicates.
- `utils/marketSnapshot.ts` — reserve parameters behind a module memo plus a
  Netlify Blobs entry, so 124 independently-revalidating pages share one set of
  RPC calls.

### Operational steps (not in code)

1. Verify `defisim.xyz` in [Google Search Console](https://search.google.com/search-console).
   DNS TXT is preferable since it survives markup changes; if that isn't an
   option, set `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` to the token from the
   "HTML tag" method and redeploy.
2. Submit `https://defisim.xyz/sitemap.xml`, then use URL Inspection to request
   indexing for `/` and `/interest`.
3. Register the same property in [Bing Webmaster Tools](https://www.bing.com/webmasters)
   (it can import from Search Console).
4. After the first deploy, confirm with Rich Results Test that the `FAQPage` and
   `WebApplication` markup validates, and re-run PageSpeed Insights to record
   the LCP change from self-hosting the fonts.

## Fonts

Fonts are self-hosted from `public/fonts/*.woff2` with `@font-face` rules in
`css/fonts.css`, both generated by:

```
node scripts/fetchFonts.mjs
```

Re-run that after changing the font stack in `theme/index.ts`. The script keeps
every unicode subset Google offers (latin, latin-ext, cyrillic, greek,
vietnamese) because the app ships 62 locales, and it collapses weights that
share a variable-font file so a browser needing two weights doesn't download the
same file twice.

The `.ttf` files in the same directory are separate: `utils/ogCard.tsx` reads
them at request time to render OG images.
